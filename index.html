Utility-First CSS & Ready-to-Use UI Components.

OrayCSS is engineered to compete directly with Tailwind CSS. No 30+ transitive packages, no runtime overhead in the browser, and no need to install external component libraries. Everything is built-in.

npm install -D oraycss Explore Components →

Standalone CLI Commands

bin/oraycss.js
1. Initialize
npx oraycss init

Generates oray.config.js with smart defaults.

2. Build CSS
npx oraycss build --minify

Compiles pure CSS ahead-of-time in milliseconds.

3. Watch Mode
npx oraycss watch

Watches source files and recompiles automatically on save.

4. Inspect Tokens
npx oraycss inspect

Breaks down discovered candidates and rule diagnostics.

How does zero-dependency AOT compilation work?
OrayCSS parses tokens using balanced bracket grammar directly in Node.js standard modules without PostCSS or Babel, compiling in single-digit milliseconds.
Can I customize the design tokens?
Yes. Configure custom semantic roles and palette mappings inside oray.config.js.
